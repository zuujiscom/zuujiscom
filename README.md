## 👋 About me

I build software of all kinds — websites, native macOS apps, game servers and games. I like things that are clean, fast and made with care.

- 🌍 Working on **[Zuujis](https://zuujis.com)**, a place to share visions for a better world
- 🍎 Writing native **macOS** utilities in Swift and C
- 🎮 Tinkering with game servers and game dev
- 🦀 Recently picking up **Rust**
- 🔒 Most of what I build is **private** — only a small selection is public
